Independent Matter bridge

Zigbee, bridged to Matter.

Zigbee2Matter keeps Zigbee2MQTT’s proven device and converter path while replacing the broker boundary with an in-process bridge bus and Matter adapters.

Implementation complete · platform acceptance still pending

What this project provides

Zigbee runtime

Coordinator discovery, pairing, interviews, availability, groups, bindings, converters and OTA boundaries remain centered on Zigbee-herdsman.

Matter exposure

Devices are mapped to persistent Matter endpoints with commissioning, fabric, reporting and multi-bridge identity boundaries.

Home Assistant

Direct, Matter and hybrid adapter paths are available. The Home Assistant add-on stores runtime data under /data.

APIs and events

Authenticated REST and WebSocket APIs provide devices, commands, diagnostics, snapshots and ordered event replay/resynchronization.

Architecture

The Zigbee network is the device-state source. Matter owns fabric, ACL, commissioning and reporting state. API and frontend clients use shared contracts instead of reaching into Zigbee internals.

Network map and language

The existing Windfront frontend includes the Zigbee network map at /map and its language menu. Zigbee2Matter preserves that UI, defaults a first visit to the browser’s supported language, keeps an existing user selection, and falls back to English when no supported browser language is available.

MQTT topics, device keys and protocol identifiers remain stable technical values; user-facing frontend text uses the frontend translation resources.

Quick start

pnpm install --frozen-lockfile
pnpm run build
pnpm start

For Docker, review docker/. For Home Assistant OS, review haos/zigbee2matter/.

Project status

The source implementation and packaging structure are present. A release should not be called fully accepted until the authorized verification pass covers installation, restart/update, backup restore, real coordinator hardware, Home Assistant runtime behavior, Matter commissioning, and both supported add-on architectures.
